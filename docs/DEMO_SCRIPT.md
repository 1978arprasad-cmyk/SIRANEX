# Prajadarbar — Demo Script for the District Collector

> Total run-time: **8 minutes**. Mobile device + laptop both pointing at
> the same deployed URL, and the Supabase SQL editor open as a "magic
> behind-the-curtain" view.

## 0. Set the stage (30 sec)

> "Honourable Collector, this is **Prajadarbar** — bilingual, mobile-first.
> Citizens lodge grievances against any government department; we track
> them end-to-end with a hard 90-day SLA."

Open `transparency.html` on a projector — the public dashboard with the
KPI tiles, department bar chart, SLA donut, and the **mandal heatmap of
Khammam**. All real data from Supabase.

## 1. The citizen (90 sec)

On the phone:

* Switch language to **తెలుగు** (top-right toggle).
* Open `register.html`.
* Tap **🎙️ తెలుగులో మాట్లాడండి** and dictate: *"మా పంచాయతీలో మంచినీటి సరఫరా లేదు, పైపులైన్ పగిలింది."*
* Pick **Mandal: Tirumalayapalem · Panchayat: Sublaid · Department: Water Supply · Subject: Pipeline Repair**.
* Tap **📍 Capture GPS**.
* Submit.
* New ID `PJD-KMM-2026-…` appears with the demo SMS / WhatsApp message
  in the `notifications` table (show on Supabase SQL editor).

## 2. The department officer (90 sec)

On the laptop, open `login.html`, click **DEMO: Officer · Water Supply**.
Inbox is now scoped. Open the new grievance:

* Change status to **Acknowledged** with remarks "Pipeline rupture, AE deployed".
* Save.
* The phone tracking page (`track.html?gid=…&m=…`) refreshes **live**
  with the new timeline entry.

## 3. The field officer (60 sec)

Click the role-switcher → **Field · Tirumalayapalem**. Filter is now by
mandal. Open the same grievance:

* Status → **Field Verified**.
* 📷 Capture an action-taken photo (live camera) with **GPS**.
* Save.

The Collector dashboard's mandal heatmap now shows the new tag.

## 4. The Collector (3 min)

Open `collector.html` (DEMO: District Collector). Walk through:

* **6 KPI tiles**: total / pending / in-progress / resolved / overdue /
  resolution-rate. *"Today we are at 73% resolution at an average of
  18 days."*
* **Department-wise stacked bar**: where the load is — Housing and
  Revenue dominate.
* **SLA donut**: Green / Amber / Red / Critical breakdown.
* **Mandal heatmap**: switch metric to *overdue* — instantly see which
  mandals are red.
* **Top-10 Pending** + **Top-10 Overdue** tables.
* **Department & Mandal scorecards** including average citizen rating.
* Click **Export to PDF** — single-click DCC/DLRC review document.
* Click **Export to Excel** — full snapshot + per-department + per-mandal
  + overdue sheets.

## 5. Closing & feedback (30 sec)

Back on the phone, mark the grievance as **Resolved** as the officer,
then on tracking page rate ★★★★★ and confirm closure. Watch the
Collector dashboard update without reload.

## Bonus (post-demo)

* `transparency.html` — public-facing aggregate stats with no PII for
  citizen trust-building.
* PWA install prompt on mobile — works fully offline for officers in
  the field.
* Supabase RLS policy view (`db/rls.sql`) — security story.
* Architecture diagram in FigJam (link generated by the bot) — system
  design for IT / NIC review.
